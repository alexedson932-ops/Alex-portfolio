ALEX PORTFOLIO - UPDATED FILES

This folder contains the updated core portfolio files:
- index.html
- style.css
- script.js

HOW TO REPLACE THE FILES:
1. Make a backup copy of your current alex-portfolio folder.
2. Extract this ZIP file.
3. Copy index.html, style.css, and script.js into your existing alex-portfolio folder.
4. Choose Replace/Overwrite when Windows asks whether to replace existing files.
5. Keep your existing images folder and other project pages (smart-business.html, phone-credit.html, hostel-management.html).
6. Open index.html in your browser and test the website.

IMPORTANT:
Only replace the three files listed above. Do not delete your images folder or existing project detail pages.
